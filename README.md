# AI Registration Assistant 🤖

## Project Overview

AI Registration Assistant is a Python-based chatbot designed to help
students register for an AI & Data Science Internship.

The chatbot uses Natural Language Processing (NLP) techniques to
understand user messages, identify intents, extract important
information, and manage the complete registration conversation.

## Features

- NLP text preprocessing
- Intent recognition
- Entity extraction
- Name validation
- Email validation
- Field validation
- Experience-level detection
- Dialog management
- Registration workflow
- Duplicate email detection
- Registration confirmation
- JSON data storage
- Search registration
- Delete registration
- Error handling
